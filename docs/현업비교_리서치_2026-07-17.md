# 현업 비교 리서치 — 전세대출 위험 스크리닝 UX 실현 가능성 검증

- 조사일: 2026-07-17 / 방법: 사이트 직접 확인(codef.io, naezipscan.com) + 네이버 뉴스 검색
- 목적: 기획서 v2의 가정("실데이터 경계", "차별성")이 현업 대비 무리가 없는지 검증

---

## 1. 등기부 자동조회 — "불가"가 아니라 "유료 B2B 대행"

**확인 사실 (codef.io 직접 확인):**
- CODEF(헥토데이터)가 부동산·등기부등본·진위확인 API를 상품으로 제공 중. 구독형 B2B 플랫폼(400+ API, 누적 호출 23억 건), 서비스 신청·협의 절차 필요, 30일 무료 체험 존재.

**기획서 반영:**
- "자동조회 불가" 표현은 부정확 → **"상용은 유료 대행 API(CODEF 등)로 자동화하는 영역, 개인·수업 프로젝트 범위에서는 사용자 직접 입력이 합리적"**으로 수정.
- 발표 방어 논리: "확장 시 CODEF류 연동으로 자동화 가능한 구조로 설계했고, v1은 입력으로 대체" — 아키텍처가 현업과 같은 모양이라는 게 오히려 강점.

## 2. 내집스캔 — 데이터 커버리지에선 못 이긴다, 각도가 달라야 한다

**확인 사실 (네이버 뉴스):**
- 주소 입력만으로 등기부등본·건축물대장 분석 + 임대인 신용·세금 체납 이력 + 다주택 보유 추정 + 다가구 선순위 보증금 추정까지 자동 제공. 누적 분석 보증금 120조 원, 리포트 100만 건+.
- 서울시 청년 전세사기 예방 사업에 채택(주소만 입력 → 종합위험도 점수, 3,000건 지원).
- KB신용정보와 부동산 권리조사 제휴(2025.12), 롯데손보와 전세사기법률비용보험 출시.

**시사점:**
- "위험 데이터를 모아 진단"하는 것 자체는 내집스캔이 이미 압도적. **내 차별점은 데이터가 아니라 ①대출 신청 여정 내장 ②점수로 뭉개지 않는 근거 카드 ③what-if 체험 학습** — 이 세 가지는 내집스캔 리포트(점수+리포트형)에 없는 각도.
- 다만 "종합위험도 점수 제시"는 내집스캔도 하므로, 발표에서 "점수형 vs 근거·체험형" 대비를 명시적으로 쳐야 함.

## 3. 은행 앱 — 신청 플로우 내 설명 UX는 아직 빈자리 (2026 기준)

**확인 사실:**
- 신한은행(2026.4): 전세사기 피해 예방 금융지원 확대, 대출 신청 단계 AI 서류 인식 도입 — 심사 효율화 중심, 위험 설명 UX 아님.
- 하나은행: '청년지킴이 전세사기 보장보험' 공동 출시(신규 전세대출 청년 3만 명 무료) — 보험(사후 보상)으로 대응.
- 즉 은행권 대응은 **심사 자동화 + 보험**이지, "신청 여정 안에서 위험을 이해시키는 UX"는 확인되지 않음 → **기획의 빈자리 가설 유효.**

## 4. 안심전세앱 — 2026년 9월 대개편 (기획서 근거 갱신 필수)

**확인 사실:**
- 정부 전세사기 방지대책(2026.3, 국토부·법무부·행안부 합동): 사후 구제 → 선제 예방으로 전환.
- **안심전세앱 9월 개편**: 흩어진 전세 계약 정보 57종 통합, 선순위 보증금·임대인 신용·체납 정보를 등급으로 공개, 위험 물건 진단.
- 이후 민간 플랫폼(직방·다방·네이버부동산·KB부동산·Npay부동산) 연계 추진.

**시사점 (양면):**
- (구근거 폐기) "임차인 87%가 앱 존재 모름(2023)"은 더 이상 못 쓴다 — 2026.3 대책으로 상황이 바뀜.
- (위협) "위험 정보 접근성" 문제는 정부가 9월에 상당 부분 해소 예정 → 정보 접근이 아니라 **이해·행동 설계**로 문제 정의를 옮겨야 함.
- (기회) 개강(9월)과 개편 시점이 겹침 → "정부가 데이터를 풀어준 시대, 그 데이터를 세입자가 이해하게 만드는 다음 단계"라는 서사로 오히려 시의성 확보. 공개 정보가 늘면 데모의 실데이터 폭도 커질 수 있음.

## 5. 종합 판정 — 기획 무리 없음, 단 문제 정의 한 줄 수정

| 검증 항목 | 판정 |
|---|---|
| 실데이터 경계 가정 | 대체로 타당. 등기부는 "불가"→"유료 B2B 대행 영역" 정정 |
| 차별성 (vs 내집스캔) | 유효하나 각도 명시 필요: 점수형 리포트 vs 여정 내장·근거·체험 |
| 차별성 (vs 은행 앱) | 유효 — 은행은 심사 자동화·보험 중심, 설명 UX 부재 |
| 문제 정의 | 수정 필요: "정보가 없다" → **"정보는 늘어나는데(9월 개편) 이해와 행동으로 이어지지 않는다"** |
| 시의성 | 강화됨 — 정부 대책·앱 개편·민간 연계가 전부 2026년 진행형 |
