# 퍼플렉시티 4차 프롬프트 — 한국 근거층 그래프 간선 초안 (상세판)

작성 2026-09-09. 목적: 규칙 축마다 한국 근거 5층(시행 법률, 계류 법안, 정부와 한은 자료, 보도, 관행)에 무엇이 있는지 모아 `graph/edges/` 초안으로 쓴다. 판단(축 정의, 층 정의, v1 값 선택)은 사람이 한다.

사용법: 공통 지시문을 먼저 붙이고 그 아래 P1~P8 중 하나를 붙여 한 번에 하나씩 돌린다. 결과의 링크는 전부 열어 원문을 확인한다(2026-09-05 엉뚱한 첨부 링크 2건 경험). 통과한 행만 간선으로 기록하고, 축마다 "받은 행 수 대 통과 행 수"를 적는다.

## 공통 지시문 (모든 프롬프트 맨 앞에 붙임)

```
[역할] 한국 원화 스테이블코인 준비금 공시 설계를 위한 1차 자료 조사. 나는 설계자이고 너는 자료 수집만 한다. 해석, 추천, 배경 설명은 하지 않는다.

[출력 형식] 요약문을 쓰지 말고 아래 표 하나만 출력한다. 표 아래에 "확인 못 한 것" 목록을 붙인다.

| 층 | 출처명 | 문서 식별자 | 조문 또는 페이지 | 날짜 | 원문 인용 | 값 | 링크 |

- 층: 1 시행 법률과 시행령과 감독규정 / 2 국회 계류 법안 / 3 정부와 한국은행 공식 자료 / 4 언론 보도 / 5 업계 관행
- 문서 식별자: 법률은 법률 번호(예: 법률 제19734호), 법안은 의안번호(예: 2201234), 보도자료는 제목과 게시 번호, 기사는 매체명과 기자명
- 조문 또는 페이지: 조문은 "제25조의2 제1항" 형식, PDF는 페이지 번호
- 원문 인용: 해당 조문이나 문장을 한 글자도 바꾸지 말고 1~2문장. 요약 금지. 인용 부호로 감쌀 것
- 값: 비율, 일수, 금액처럼 숫자로 떨어지는 값이 있으면 숫자만. 없으면 빈칸
- 날짜: 법률은 시행일, 법안은 발의일, 자료는 게시일, 기사는 보도일. YYYY-MM-DD
- 링크: 1층은 법제처 https://www.law.go.kr/법령/법령명/조문번호 형식(예: https://www.law.go.kr/법령/전자금융거래법/제25조의2), 2층은 국회 의안정보시스템 법안 상세 페이지, 3층은 fsc.go.kr 또는 bok.or.kr 원문 페이지, 4층은 기사 원문, 5층은 회사 공식 페이지. 블로그, 위키, 요약 사이트, 검색 결과 페이지, 목록 페이지 링크 금지

[규칙]
- 층마다 최소 1행. 그 층에 아무것도 없으면 출처명에 "없음"이라고 쓴 행 1개
- 확인하지 못한 항목은 표에 넣지 말고 "확인 못 한 것"에 항목 번호와 함께 적는다
- 4층(보도)의 내용을 1층이나 3층에 넣지 않는다. 기사가 "금융위가 검토 중"이라고 써도 금융위 원문을 못 찾았으면 4층이다
- 법안은 반드시 의안번호로 구분한다. "여러 법안이"처럼 뭉뚱그리지 않는다
- 같은 내용이 여러 층에 있으면 층마다 따로 행을 만든다
- 링크는 실제로 열리는 페이지여야 한다. 확신이 없으면 링크 칸에 "미확인"이라고 쓴다
- 아래 [이미 아는 것]은 다시 설명하지 않는다. 그 다음 단계만 조사한다
```

## P1 준비자산 보관과 운용 (첫 실행 축)

```
[주제] 원화 스테이블코인 준비자산의 보관과 운용 요건. 한국에 이미 있는 유사 제도의 조문과 계류 법안의 값을 모은다.

[이미 아는 것] 전자금융거래법 개정으로 2024-09-15부터 선불충전금을 100% 이상 별도관리(신탁, 예치, 지급보증보험)하고 운용은 국채와 지방채와 은행 예치로 제한한다. 가상자산이용자보호법(2024-07-19 시행)은 거래소 예치금을 관리기관에 예치 또는 신탁하게 한다. 코빗은 원화 예치금을 신한은행에 분리보관한다고 공시한다.

[확인할 것]
1. 전자금융거래법의 선불충전금 별도관리 조문. 제25조의2로 알려져 있는데 정확한 조문 번호와 항 번호. 그리고 시행령에서 관리 방식 3가지, 운용 허용 자산, 관리기관 범위를 정한 조문 번호. 각 조문의 원문 첫 문장. 답 형식: 조문 번호 + 원문
2. 같은 법이나 시행령에서 "100분의 100" 같은 비율 표현이 나오는 정확한 조문과 원문. 답 형식: 조문 + 원문 + 값
3. 가상자산이용자보호법에서 예치금 보호 조문(제6조로 알려짐)과 시행령에서 관리기관을 은행으로 한정한 조문. 원문. 답 형식: 조문 + 원문
4. 국회 계류 중인 디지털자산기본법안과 스테이블코인 법안 각각에서 준비자산 보유비율, 허용 자산 종류, 보관 방식을 정한 조문. 법안마다 별도 행. 답 형식: 의안번호 + 조문 + 원문 + 값
5. 금융위원회 2025-01-15 자료(https://www.fsc.go.kr/no010101/83855)에서 "준비자산에 대한 엄격한 관리의무"와 "상환청구권 보장" 문장의 앞뒤 문단 원문. 답 형식: 원문 3문장
6. 한국은행 통화신용정책보고서 2026년 3월호에서 준비자산 관련 문장. 페이지 번호와 PDF 링크. 답 형식: 페이지 + 원문
7. "준비자산 100%, 국내 보관, 이자 지급 금지"를 처음 보도한 기사. 매체, 날짜, 기사가 인용한 발언자나 문서. 답 형식: 매체 + 날짜 + 인용 출처 + 링크
8. 코빗 https://insights.korbit.co.kr/reserves 와 업비트 공지사항에서 원화 예치금 보관 은행명이 적힌 정확한 문구와 게시일. 업비트는 케이뱅크로 알려져 있는데 공식 문구로 확인. 답 형식: 원문 + 게시일 + 링크

[목표 예시]
| 1 | 전자금융거래법 | 법률 제19734호 | 제25조의2 제1항 | 2024-09-15 | "선불업자는 선불충전금을 ... 별도로 관리하여야 한다" | 100 | https://www.law.go.kr/법령/전자금융거래법/제25조의2 |

[하지 말 것] 전금법 개정 배경(머지포인트 사태) 설명, 스테이블코인 개념 설명, 해외 규제 비교. 이 프롬프트는 한국 자료만.
```

## P2 컨소시엄과 발행자 자격

```
[주제] 원화 스테이블코인 발행자 자격과 은행 컨소시엄 구조. 해외 규정에 없는 한국 고유 축이라 근거를 층별로 정확히 가른다.

[이미 아는 것] 한국은행 통화신용정책보고서 2026년 3월호는 은행 중심 컨소시엄에 우선 발행을 허용하는 방안이 바람직하다고 썼다. 금융위 2026-03-04 가상자산위원회 자료는 "은행 중심(지분 50%+1) 스테이블코인 발행"을 논의 항목으로 적었다. 은행 컨소시엄은 유니카(신한, 우리, NH, 케이뱅크 등)와 하나은행 주도(BNK, iM, SC, OK) 두 갈래로 보도됐다.

[확인할 것]
1. 한국은행 보고서의 컨소시엄 문장 원문 전체(문단 단위)와 페이지 번호, PDF 링크. 답 형식: 페이지 + 원문 문단
2. 금융위 2026-03-04 자료(https://www.fsc.go.kr/po010101/86373)의 "지분 50%+1" 문장과 그 앞뒤 문장 원문. 답 형식: 원문 3문장
3. 계류 법안별 발행자 자격 조문. 은행 한정인지, 은행 지분 요건이 있는지, 최저 자본금이 있는지. 법안마다 별도 행. 답 형식: 의안번호 + 조문 + 원문 + 값
4. 은행법에서 은행의 다른 회사 출자 한도 조문(제37조로 알려짐)과 금융지주회사법의 자회사 편입 조문. 은행이 발행 법인에 50% 초과 출자하려면 어떤 조문의 예외나 인가가 필요한지. 답 형식: 조문 + 원문 + 값(15%, 20% 등)
5. 컨소시엄 참여 은행별 준비금 보관 분담, 참여사 이탈, 참여사 파산 시 준비금 귀속을 다룬 조항이나 공식 논의. 어느 층에라도 있으면 기록, 없으면 층마다 없음. 이 항목은 "없음"이 확인되는 것 자체가 중요하다
6. 유니카와 하나은행 컨소시엄의 공식 발표(은행 보도자료)와 참여사 목록, 발표일. 5층. 답 형식: 참여사 + 날짜 + 링크
7. 비교용 1행만: 일본 3대 은행 공동 발행의 법적 구조(신탁 수익권형)를 설명한 일본 금융청이나 해당 은행의 공식 자료. 답 형식: 구조 한 줄 + 링크

[목표 예시]
| 3 | 금융위원회 26년 제1차 가상자산위원회 개최 | 보도자료 2026-03-04 | 본문 논의사항 | 2026-03-04 | "은행 중심(지분 50%+1) 스테이블코인 발행 및 가상자산거래소에 대한 소유 분산 기준 필요성" | 50 | https://www.fsc.go.kr/po010101/86373 |

[하지 말 것] 컨소시엄의 장단점 분석, 어느 은행이 유리한지 평가.
```

## P3 국내 보관과 외환

```
[주제] 준비자산의 국내 보관 의무와 역외 보유 제한. 원화가 국제결제통화가 아니라서 생기는 한국 고유 축.

[이미 아는 것] "준비자산 국내 보관"은 지금까지 보도 단계로만 확인됐고 금융위 원문에서는 못 찾았다.

[확인할 것]
1. 외국환거래법과 외국환거래규정에서 거주자의 해외 예금과 해외 증권 취득에 대한 신고 조문(외국환거래규정 제7-11조 등으로 알려짐). 국내 법인이 원화 또는 외화 자산을 해외 금융기관에 두려면 어떤 절차인지. 답 형식: 조문 + 원문
2. 계류 법안 중 준비자산의 국내 보관, 국내 금융기관 예치, 국내 수탁을 명시한 조문. 의안번호별. 없으면 없음. 답 형식: 의안번호 + 조문 + 원문
3. "국내 보관" 요건을 처음 보도한 기사. 매체, 날짜, 기사가 인용한 출처(관계자 발언인지 문서인지). 답 형식: 매체 + 날짜 + 인용 출처 + 링크
4. 한국은행 또는 금융위 자료에서 자본유출, 통화주권, 달러 스테이블코인 잠식 우려를 국내 보관과 연결한 문장. 답 형식: 출처 + 원문
5. 비교용: 홍콩 HKMA 감독지침과 싱가포르 MAS 규정에 준비자산 보관 지역 요건이 있는지. 있으면 조문 번호와 원문, 없으면 없음. 답 형식: 조문 + 원문

[목표 예시]
| 4 | 매체명 | 기자명 | 기사 본문 | 2026-MM-DD | "금융당국은 준비자산을 국내에 보관하도록 ..." | | 기사 링크 |

[하지 말 것] 외환 규제의 역사 설명, 정책 찬반.
```

## P4 분리보관 기관 실명 공개

```
[주제] 고객 자산 분리보관 기관의 실명 공개가 한국에서 의무인지 관행인지. 미국은 아직 질문 단계라서 한국이 앞선 항목일 수 있다.

[이미 아는 것] 코빗은 원화 예치금 분리보관 은행을 신한은행으로 공시 페이지에 명시한다. 미국 OCC 제안 규정(91 FR 10202, 2026-03-02) Question 91은 준비자산 보유 예금기관의 실명 공개를 요구할지를 질문으로 남겼다.

[확인할 것]
1. 가상자산이용자보호법, 시행령, 감독규정에서 예치금 관리기관의 이름을 이용자에게 공시하라는 의무 조문이 있는지. 있으면 조문과 원문, 없으면 없음. 의무인지 관행인지 구분이 이 항목의 핵심. 답 형식: 조문 + 원문, 또는 없음
2. 코빗 https://insights.korbit.co.kr/reserves 의 은행명 문구와 게시일. 업비트, 빗썸, 코인원의 예치금 은행명 공시 문구와 위치(공지사항인지 약관인지 별도 페이지인지). 거래소마다 별도 행. 답 형식: 원문 + 위치 + 게시일 + 링크
3. 각 거래소 실사보고서를 작성한 회계법인 이름과 보고서 공개 위치. 최근 1건씩. 답 형식: 회계법인 + 기준일 + 링크
4. 계류 법안 중 준비자산 수탁기관 공개를 명시한 조문. 의안번호별. 답 형식: 의안번호 + 조문 + 원문
5. 전자금융거래법과 시행령에서 선불충전금 관리기관의 이름을 공시하라는 조문이 있는지. 답 형식: 조문 + 원문, 또는 없음
6. 미국 OCC 제안 규정 Question 91의 원문 문장(Federal Register 인쇄면 10258 부근). 비교용 1행. 답 형식: 원문 + 링크
```

## 결과 처리

1. 링크를 전부 열어 인용 문구가 원문에 있는지 확인. 없으면 그 행 폐기.
2. 통과한 행을 `graph/edges/<축>.json`에 층 라벨과 함께 기록. 확정 여부는 기본 false.
3. 축마다 "받은 행 수 / 원문 확인 통과 행 수 / 층 오분류 행 수"를 기록. 이게 AI 품질 비교 실험실의 첫 수치.
4. P8 결과는 `graph/corpus.json`의 문서 노드 목록으로 먼저 쓴다. P1~P7은 그 목록의 의안번호를 참조한다.
