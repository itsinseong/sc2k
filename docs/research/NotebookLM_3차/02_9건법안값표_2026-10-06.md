정무위원회 계류 제정안 9건의 원문을 에이전트 9명이 법안마다 처음부터 읽고, 값마다 조문 번호와 원문 인용으로 정한 표다. NotebookLM 원문 대조 때 검증자들이 내린 판정과, 판정기 규칙 파일 `site/jurisdictions/kr-v1.json`과도 대조했다. 원본 데이터는 같은 이름의 json.

**표에서 바로 보이는 것**

- 9건 모두 정하지 않은 값: 레포 만기(R04), 보관기관 실명 공개(R12), 예금 아님 고지(E4), 공동 발행(K01), 은행 지분 요건. 공시안의 D-03(보관기관 실명 공개)은 9건 어디에도 없는 값을 새로 제안하는 것이다.
- 현금성 최저 비율(R05)은 안도걸, 최보윤 2건만 대통령령에 맡겼고 나머지 7건은 위임조차 없다. 공시안 D-05(잠정 15%)는 법안이 아니라 해외 값과 발행사 실측으로만 뒷받침된다.
- 공개 기한(R10)을 숫자로 정한 것은 김현정안(다음 달 5일) 하나다.
- 상환 기한은 3일(이강일, 박상혁), 3영업일(안도걸), 5일(김재섭), 5영업일(최보윤), 10일(김은혜), 10일 범위 위임(김현정), 숫자 없이 위임(김성원), 없음(민병덕)으로 갈린다. 상환 수수료를 금지한 법안은 없고 3건은 부과기준이나 수수료 공시만 요구한다.
- 외부 검증은 감사(김은혜 분기, 김성원 분기, 김현정 반기, 이강일 연 1회, 김재섭 주기 위임)와 검토 또는 점검(안도걸 분기 검토, 최보윤 분기 검토, 박상혁 분기 점검)으로 갈린다.
- 은행 지분 요건(50%+1주)은 9건 어디에도 없다. 정부와 한국은행 논의에서 나온 것이다.

## 3. kr-v1.json과 다른 칸

판정기 규칙 파일에 적힌 9건 값과 원문이 다르거나 빠진 칸이다. 아직 고치지 않았다.

**민병덕 (2210736)**
- R03: bills 배열에 민병덕 행 없음 (안도걸 외 5명 365일, 박상혁 null만 있음) → 정함 없음, 스테이블코인 조문에 국채 만기 문구 없음 (제103조)
- R08: bills 배열에 민병덕 행 없음 (안도걸, 김은혜, 김현정 3건만 있음) → 정함 없음, 준비자산 검증 문구 없음 (제103조)
- R10: bills 배열에 민병덕 행 없음 (김현정, 안도걸, 김은혜 3건만 있음) → 정함 없음, 공개 기한 문구 없음 (제103조)
- R01: bills 민병덕 행 value null, note '비율 없음, 환불준비금 계획을 인가 요건으로'에 조문 번호가 없음 → 정함 없음 (제103조제2항제5호). 값은 일치하고 조문 표기만 빠짐
- R13: bills 민병덕 행 value null, note '원문에서 기한 문구 찾지 못함'에 조문 번호가 없음 → 상환 기한 정함 없음, 환불 방법 계획의 포함 사항만 대통령령 위임 (제103조제2항제5호). 값은 일치하고 위임 사실과 조문 표기만 빠짐
- R14: candidates article이 안도걸 제17조, 김재섭 제128조, 김현정 제31조만 인용하고 민병덕 언급 없음 → 이자 금지 조문 없음, 정함 없음 (제103조). 금지 법안 목록과 모순은 없으나 민병덕 행이 빠짐
- R15: candidates article이 안도걸 제16조제5항, 김은혜 제13조제5항만 인용하고 민병덕 언급 없음 → 준비자산 경영진 인증은 정함 없음. 제104조제5항은 발행신고서 서명이라 해당하지 않음
