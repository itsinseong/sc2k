## 2. 이 학생이 은행 디지털 기획 신입을 노린다면 더 나은 프로젝트가 있는가

있음: **은행형 원화 스테이블코인 발행, 환매, 사고 대응 운영 콘솔**. 고객의 발행과 환매, KYC, 한도, 수수료, 준비금 유동성, 수탁은행 접근 불능, 공급량 불일치, 사고 처리 SLA를 하나의 업무 흐름으로 설계한다. 규정 정리를 실제 고객 여정과 내부 의사결정으로 연결하므로 디지털 기획 직무와 더 가깝다. 대신 국제 규제 비교의 폭과 PDF 파싱 비중을 잃는다.

## 3. 살아남는 강점

- Circle 보고서에는 파싱 결과를 원문 합계와 대사할 수 있는 표와 세부 항목이 있다.
- 조문, 데이터 필드, 화면 표시 항목을 추적 가능하게 연결하는 구조는 검증할 수 있다.
- 공개 자료만으로 최소 시연물을 만드는 것은 예산과 기간 안에서 가능하다.

## 4. 판정

**go-with-changes**: 현재의 국제 공통 공시 프레임은 성립하지 않지만 비교 단위, 데이터 검증, 사용자의 의사결정을 다시 정의하면 프로젝트 자체는 남는다.

- 바젤을 관할권 매트릭스에서 분리하고 MiCA를 EMT 기준으로 다시 분석한다.
- 공급량의 기준시각과 제외항목을 정규화하고 합계 대사와 실패 검사를 성공 기준에 넣는다.
- 화면 사용자를 은행 준법 또는 자금운영 담당자로 특정하고 판단 항목, 예외 처리, KPI를 설계한다.
