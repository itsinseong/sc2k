# 스테이블워치(StableWatch) — 한 장 개요

StableWatch · 미디어프로젝트 2026-2

은행 디지털자산 TF·컴플라이언스 담당자가 동향 보고서에 올리기 전, 검증된 사실만 근거와 함께 골라주는 인텔리전스 도구.

**태그**: 3층 근거 구조 · 5단계 판정 게이트 · AI 오판 18건 자기 공개 · 697건 주장·310건 기사 실데이터

## 왜 필요한가

문제 정의는 신뢰 수준이 다른 3개 층으로 구성된다.

1. **시장 사실 · 확인됨** — 은행권이 조직 단위로 움직인다. 8개 은행 스테이블코인 컨소시엄, KB 상설 분과, 카드사 9곳 TF + 공동상표 30건 출원.
2. **자체 실측 · archive.db** — 코인 매체 원문은 검증 부담이 크다. 기사의 상당수가 주제외 노이즈, 신뢰도 값은 0.6 구간에 43% 집중(미보정), 명백한 AI 오판 18건.
3. **업계 신호 · 확인됨** — 금융권은 "쓰되 통제"를 원한다. 금융권 공동채용박람회 AI Agent 세션, 은행연합회 FRC 2026 "속도보다 통제".

## 사용자 흐름

컴플라이언스 담당자가 도구에 들어와 근거까지 도달하는 경로 — 4개 화면.

진입(매일 아침, 동향 보고서 작성 전 오늘 검증 통과된 주장부터 확인) → **화면1 데일리 브리핑**(검증 통과 카드 피드 + 오늘 걸러진 건수·사유 패널) → **화면2 규제 현황판**(미국·EU·한국 3레인 타임라인 + AML·제재 레인) → **화면3 질의 대응 검증기**("삼성 발행 확정?" 같은 질의 입력 → 5단계 판정 + 근거 30초 내 제시) → **화면4 데이터 분석 리포트**(매체별 신뢰도 분포, AI 오판 3유형, 한/영 프레이밍 비교)

### 문서 간 불일치 3건 — 실측으로 확인, 화면 개발 전 반영 필요

1. **트리비얼 건수**: `정제결과_요약.md`는 최종 187건(26.8%)이라 적었지만 실제 `claims_typed` 테이블·CSV는 **190건(27.3%)**. 문서가 언급한 QC 정정 7건 중 3건(id 42·197·340)이 데이터에 반영되지 않은 상태.
2. **수집 기간**: PRD는 "85일 수집", "5/30부터 약 3개월"이라 하지만 `articles.fetched_at` 실측 범위는 원본·사본 모두 2026-06-03~07-25로 **52일**(사본 절단 아님, 원본도 동일). 8월분은 전무.
