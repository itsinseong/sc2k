# 1차 아이디어 발표 시나리오

5분 이내. 슬라이드 6장에 4분, 프로토타입 시연에 1분. 담당 교수가 시간 엄수를 중시하므로 넘기지 않는다. 프로토타입은 슬라이드에 넣지 않고 발표 끝에 실물로 띄운다.

## 시간 배분

| 구간 | 시간 | 누적 |
|---|---|---|
| 1장 표지 | 10초 | 0:10 |
| 2장 배경 | 45초 | 0:55 |
| 3장 내용 | 55초 | 1:50 |
| 4장 어떻게 | 70초 | 3:00 |
| 5장 관련 사례 | 35초 | 3:35 |
| 6장 사회진출 | 25초 | 4:00 |
| 프로토타입 시연 | 55초 | 4:55 |

## 장별 할 말

**1장.** 이름과 한 줄만. "해외 규제와 실제 발행사 데이터를 근거로 한국의 공시 기준을 직접 제안하는 프로젝트입니다."

**2장 배경.** 그림부터 가리킨다. "국회에 올라온 법안 여덟 건이 환매 기한을 3일부터 10일까지 제각각으로 정해 놨습니다. 정부안은 아직 없습니다." 그다음 네 줄을 빠르게 읽는다. 은행이 발행하는 시대가 오고, 발행하면 매달 준비금을 공시해야 하는데, 무엇을 어떻게 공시할지가 없다는 순서.

**3장 내용.** 제일 크게 말할 문장. "규정이 아직 없으니 제가 기준을 만들어 제안하겠습니다." 그다음 셋을 짚는다. 무엇을 제안하는지, 근거는 어디서 가져오는지, 타당한지 어떻게 보는지.

**4장 어떻게.** 여기가 핵심이라 시간을 가장 많이 준다. 세 단계를 먼저 짚고 예시로 들어간다. "미국은 현금성 자산을 30% 이상 두라고 합니다. 그런데 세계 최대 발행사의 넉 달치 공시를 계산해 보니 실제로는 14%였습니다. 미국도 이걸 의무가 아니라 권장으로 뒀습니다. 그래서 한국 제안값은 30%가 아니라 15%로 잡았고, 왜 그렇게 정했는지를 기록으로 남깁니다." 근거를 대는 방식이 이렇다는 것만 전달하면 된다.

**5장 관련 사례.** 넷을 한 줄씩. 마지막에 "앞의 셋은 있는 규정을 정리하거나 판정합니다. 없는 규정에 값을 정해 제안하는 곳은 제가 찾은 범위에서 없었습니다."

**6장 사회진출.** 은행 디지털 기획은 규제가 정해지기 전에 서비스를 설계해야 하는 자리라는 것 한 문장. 남길 것 네 가지를 빠르게.

## 시연 55초

띄우는 것은 판정기 프로토타입. 순서를 외워 둔다.

1. **10초** 화면을 띄우고 "실제 발행사 넉 달치 공시를 넣어 둔 화면입니다. 지금은 미국 기준입니다."
2. **15초** 관할권을 홍콩으로 바꾼다. "같은 자료인데 공개 주기 규칙이 미충족으로 바뀝니다. 홍콩은 주간 공개를 요구하기 때문입니다."
3. **15초** 한국 시나리오로 바꾼다. "한국으로 바꾸면 규정 없음이 몰립니다. 이 칸들이 제가 값을 정해야 하는 자리입니다."
4. **15초** 고객 화면으로 내려간다. "고객 입장에서는 수수료와 처리기한이 확인 불가로 나옵니다. 공시 규정이 없어서 생기는 일이고, 이걸 없애는 게 이 프로젝트의 목표입니다."

## 준비

- 프로토타입은 로그인 없이 열리도록 로컬 파일로 준비한다. `prototype/판정기_프로토타입.html`을 브라우저로 열어 두고 탭을 미리 띄워 놓는다. 아티팩트 링크는 비공개라 발표장에서 로그인이 필요할 수 있다.
- 슬라이드는 pptx로 변환해 제출한다. 다른 포맷은 인정되지 않는다.
- 시연 중 브라우저 확대는 미리 맞춰 둔다. 뒷자리에서 표가 보여야 한다.
- 시간이 모자라면 5장 관련 사례를 줄이고 시연을 지킨다. 동료평가가 40%라 눈에 보이는 것이 남는다.
